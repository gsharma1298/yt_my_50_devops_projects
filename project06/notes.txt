34. INTERVIEW QUESTIONS
============================================================

Q1. What is Docker?

ANSWER:

Docker is a containerization platform used to package and
run applications with their dependencies.


------------------------------------------------------------

Q2. What is a Docker image?

ANSWER:

A Docker image is a read-only template used to create
containers.


------------------------------------------------------------

Q3. What is a Docker container?

ANSWER:

A container is a running instance of a Docker image.


------------------------------------------------------------

Q4. What is Dockerfile?

ANSWER:

Dockerfile contains instructions used to build a Docker image.


------------------------------------------------------------

Q5. What does -p 80:80 mean?

ANSWER:

It maps port 80 of the EC2 host to port 80 of the
Docker container.


------------------------------------------------------------

Q6. Why use Docker volumes?

ANSWER:

Volumes provide persistent storage outside the container
lifecycle.


------------------------------------------------------------

Q7. What is Docker network?

ANSWER:

Docker network allows containers to communicate with
each other.


------------------------------------------------------------

Q8. Why use Docker Compose?

ANSWER:

Docker Compose allows us to define and manage
multi-container applications using YAML.


------------------------------------------------------------

Q9. Image vs Container?

ANSWER:

Image = Template

Container = Running instance of the image


------------------------------------------------------------

Q10. How do you check Docker container logs?

ANSWER:

docker logs <container-name>
