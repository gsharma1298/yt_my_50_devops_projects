STEP 3: UPDATE UBUNTU PACKAGES
==================================================


sudo apt update
sudo apt upgrade -y
sudo apt install -y curl git maven wget gnupg ca-certificates fontconfig xauth x11-apps

sudo apt install -y openjdk-21-jdk


==================================================
STEP 5: INSTALL JENKINS LTS
==================================================


sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
  https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key

echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" \
  https://pkg.jenkins.io/debian-stable binary/ | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null

sudo apt update -y
sudo apt install jenkins -y

==================================================


mvn clean package


==================================================
STEP 14: CREATE THE JENKINS PIPELINE JOB
==================================================

1. Open Jenkins.
2. Click New Item.
3. Enter:

Project07-CI

4. Select Pipeline.
5. Click OK.

Under Pipeline, configure:

Definition:
Pipeline script from SCM

SCM:
Git

Repository URL:
https://github.com/gsharma1298/yt_my_50_devops_projects.git

Branch Specifier:
*/main

Script Path:
project07/Jenkinsfile

Save the job.

For a private repository, configure an appropriate GitHub credential and select it in the SCM settings.

==================================================
STEP 16: RUN YOUR FIRST JENKINS BUILD
==================================================

1. Open Project07-CI.
2. Click Build Now.
3. Open the latest build.
4. Click Console Output.



==================================================
STEP 18: ENABLE THE JENKINS WEBHOOK TRIGGER
==================================================

Jenkins > Project07-CI > Configure

Under Build Triggers, select:

GitHub hook trigger for GITScm polling

Click Save.

==================================================
STEP 19: ADD A WEBHOOK IN GITHUB
==================================================

Open:

https://github.com/gsharma1298/yt_my_50_devops_projects

Navigate to:

Settings > Webhooks > Add webhook

Configure:

Payload URL:
https://YOUR_JENKINS_DOMAIN/github-webhook/

Content type:
application/json

Events:
Just the push event

Active:
Enabled
